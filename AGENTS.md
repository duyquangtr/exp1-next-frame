# Exp 1: next-frame conv predictor

Personal research project by Stephen Tran (not a class assignment). Teach first: explain the plan in plain words, including tensor shapes in and out, then wait for my OK before writing or editing code.

## Goal
Predict the next 32×32 frame of a synthetic bouncing-blob video from the last K=3 frames. The network predicts a residual, adds it to the last frame, and clamps to [0, 1]. About 198k params (`NextFrame`).

- Baselines: copy-last (the real bar) and mean-frame (train frames only; the floor). Constant-velocity (`2·f(t) − f(t−1)`, clamped) comes later.
- Metrics: val MSE and SSIM on pixels in [0, 1], plus open-loop rollout-10 MSE (the model eats its own predictions).
- Split by video, never by window (adjacent windows share K−1 frames).
- Report mean ± spread across seeds 0, 1, 2. A smoke run is not a result.
